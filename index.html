Kevin Work Sync

A personal automation tool used only by its owner. It updates the owner's own spreadsheets and documents through the Google Sheets API and Google Docs API.

개인 업무 자동화 도구입니다. 소유자 본인만 사용하며, 본인이 편집 권한을 가진 스프레드시트와 문서를 Google Sheets API·Docs API로 갱신합니다.

  • Users: the owner only (not offered to the public)
  • Scopes: spreadsheets, documents
