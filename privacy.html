Privacy Policy

Kevin Work Sync is a personal tool used only by its owner. It is not offered to other users.

Data accessed

With the owner's consent, the tool reads and writes only the specific Google Sheets and Google Docs files the owner works on (scopes: spreadsheets, documents). It does not access Gmail, Drive file listings, contacts, or any other Google data.

Storage

OAuth tokens are stored only on the owner's own computer with owner-only file permissions. No data is stored on any server operated for this tool.

Sharing

No data is sold, shared with, or transferred to any third party. Data is not used for advertising or for training any model.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
